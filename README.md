# RentCar, application web de location de véhicules

Application PHP / MySQL réalisée à partir du modèle UML du TP 2 (ECE Mastères, Conception de systèmes d'information).
Chaque acteur (Visiteur, Client, Employé) réalise ses cas d'utilisation, et chaque page affiche sa procédure étape par étape.

Documentation complète à venir dans `RAPPORT.md`.
